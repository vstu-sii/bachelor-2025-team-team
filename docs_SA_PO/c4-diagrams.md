## Выбор и обоснование технологий

| Компонент              | Технологии                   | Обоснование                                                                  |
| ---------------------- | ---------------------------- | ---------------------------------------------------------------------------- |
| **Frontend**           | React + Tailwind             | Лёгкий SPA с хорошей интеграцией REST API и современным UI                   |
| **Backend**            | FastAPI (Python)             | Высокая скорость, асинхронность, удобная интеграция с LLM и Celery           |
| **LLM Integration**    | OpenAI API / HuggingFace Hub | Надёжный внешний источник AI-моделей                                         |
| **Очередь задач**      | Celery + Redis               | Асинхронная обработка AI-запросов, поддержка горизонтального масштабирования |
| **База данных**        | PostgreSQL                   | Реляционная СУБД с надёжностью и транзакционностью                           |
| **Файловое хранилище** | MinIO / AWS S3               | Масштабируемое хранение файлов резюме и отчётов                              |
| **Контейнеризация**    | Docker + Docker Compose      | Простое развертывание и масштабирование компонентов                          |
| **CI/CD**              | GitHub Actions               | Автоматизация сборки и тестов                                                |

## Описание интерфейсов компонентов

| **Компонент**                               | **Назначение**                            | **Формат данных**                          | **Протокол / Технологии**            |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------  | ------------------------------------------ | ------------------------------------ |
| **Frontend (Web UI)**                   | Веб-интерфейс пользователя (загрузка вакансий, резюме, настройка анализа, просмотр рейтингов) | HTTPS, REST API, React / Vue         |
| **Backend API (AI HR Assistant Server)** | Обработка запросов от Frontend, оркестрация анализа и генерации вопросов      | JSON, PDF/DOCX      | FastAPI / Django REST, Celery, Redis |
| **LLM Connector**                        | Связь с внешней языковой моделью (анализ резюме, генерация вопросов)                                                                                                                                                                                                           | JSON (prompt + response)                   | HTTPS, OpenAI API / LangChain        |
| **Database (PostgreSQL)**                | Хранение структурированных данных (вакансии, кандидаты, скоринг, вопросы)      | SQL / ORM объекты       | PostgreSQL, SQLAlchemy / Django ORM  |
| **File Storage (S3 / MinIO)**           | Хранение файлов резюме, отчётов и экспортов        | Binary (PDF/DOCX)     | HTTPS, S3 API, MinIO / AWS S3        |
| **External HR Systems**                  | Интеграция с внешними системами подбора персонала                                             | JSON        | REST API, OAuth 2.0, HTTPS           |
