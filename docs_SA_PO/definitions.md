
# **DoR/DoD критерии**

  ### **Definition of Ready (DoR):**
1. Детальные Критерии Приемки (Acceptance Criteria):
  1) Для анализа резюме: "Система должна извлекать и классифицировать навыки (hard skills) с точностью не менее 95%".
  2) Для ранжирования: "Если скиллы кандидата совпадают с требованиями вакансии на 80% и выше, он попадает в группу "Топ-кандидаты".
  3) Для генерации вопросов: "Вопросы должны генерироваться только для кандидатов с score > 80% и должны ссылаться на конкретный опыт из их резюме".
2. Готовность данных/модели: Определено, какие данные нужны для обучения/тестирования.
3. Готовый UI/UX:  Макеты интерфейса для отображения скора, ранжированного списка, сгенерированных вопросов.

  ### **Definition of Done (DoD) для функций:**
1. Готовый код
2. Модель протестирована
3. Проведено интеграционное тестирование
4. Проведено UI/UX тестирование
5. Описана документация


  ### **Метрики успеха продукта для HR AI.**
1. Количество успешных наймов, совершенных с помощью системы
2. Время на закрытие вакансии (Time-to-Hire)
3. Количество активных HR-пользователей в неделю 
4. Точность ранжирования 
5. Релевантность сгенерированных вопросов


  ### **KPI для каждого спринта для команды**
1. Скорость команды
2. Количество багов, найденных после сдачи задачи на тестирование
3. Процент выполненных задач, соответствующих DoD.
4. Время цикла
