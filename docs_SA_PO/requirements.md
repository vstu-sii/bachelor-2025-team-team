# Технические требования к системе «AI HR Assistant»
### **1. Назначение системы**

Система предназначена для автоматического анализа резюме кандидатов и описаний вакансий с целью определения уровня соответствия, ранжирования кандидатов и генерации персонализированных вопросов для интервью на основе выявленных пробелов и опыта.

### **2. Общие характеристики**

| Параметр | Описание |
| --- | --- |
| Тип системы | Веб-приложение с серверной обработкой данных и интеграцией с внешними AI API |
| Основные пользователи | Директор / Основатель / HR-специалист |
| Технологическая архитектура | Клиент–сервер с интеграцией LLM |
| Среда исполнения | Веб-браузер и серверное окружение |
| Тип данных | Текстовые документы (PDF, DOCX, TXT) |
| Интеграции | LLM-провайдеров (mistral) |


### **3. Функциональные требования (Functional Requirement)**

**3.1. Управление вакансиями**
FR-1: Возможность загрузки описания вакансии. 

FR-2: Автоматическое извлечение ключевых требований и навыков с помощью LLM.

FR-3: Возможность редактирования и сохранения вакансии.


**3.2. Управление кандидатами**

FR-4: Загрузка одного или нескольких резюме.

FR-5: Распознавание текста и структурирование данных кандидата.

FR-6: Отображение статуса обработки каждого резюме.


**3.3. Настройка анализа**

FR-7: Два режима анализа: автоматический и ручной.

FR-8: Сохранение пользовательских настроек.

FR-9: Отображение критериев, извлечённых из вакансии.

**3.4. Анализ и ранжирование кандидатов**

FR-10: Передача данных в LLM для анализа.

FR-11: Оценка степени соответствия по каждому критерию.

FR-12: Расчёт итогового скоринга.

FR-13: Отображение списка кандидатов по рейтингу.

FR-14: Объяснение оценки (explainability).

**3.5. Генерация интервью-вопросов**

FR-15: Выбор кандидатов для генерации вопросов.

FR-16: Формирование запроса в LLM с данными кандидата и вакансии.

FR-17: Генерация вопросов и кейсовых заданий.

FR-18: Возможность редактирования перед утверждением.

**3.6. Экспорт и интеграции**

FR-19: Экспорт в формат PDF.

FR-20: Включение данных кандидата, вопросов и плана беседы.

FR-21: Сохранение истории экспортов.

FR-22: Интеграция с HRM API.

### **4. Нефункциональные требования**

| Категория | Требование |
| --- | --- |
| Производительность | Обработка до 20 резюме одновременно; анализ одного кандидата ≤ 10 секунд |
| Надёжность | Сохранение промежуточных результатов при сбое |
| Масштабируемость | Поддержка масштабирования AI-компонентов |
| Безопасность | Хранение данных с обезличиванием, HTTPS, токенизированный доступ к API |
| Интерфейс | Адаптивный дизайн для desktop и mobile |

### **6. Технологии и архитектура**

Frontend: React / Vue.js + TailwindCSS

Backend: Python (FastAPI / Django REST)

AI-интеграция: OpenAI 

Очередь задач: Celery + Redis

База данных: PostgreSQL

Хостинг: Docker + Kubernetes / Cloud
