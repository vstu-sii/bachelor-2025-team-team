# Контроль интеграции AI HR Assistant
## Сценарий проверки (MVP)
1. Авторизация
2. Создание вакансии
3. Загрузка резюме кандидатов
4. Анализ и ранжирование (Backend вызывает LLM для анализа навыков и опыта кандидатов)
5. Выбор кандидатов (Пользователь выбирает 1–2 кандидатов из списка)
6. Генерация вопросов для интервью (Система передаёт данные вакансии и кандидата в LLM)
7. Экспорт отчёта
## Фактическое состояние:
1. Авторизация -
2. Backend API -
3. LLM -
4. PostgreSQL -
5. Frontend/UI -
## Проверка работы всех компонентов:
Backend API ↔ PostgreSQL: соединение установлено, регистрация/авторизация и сохранение истории работают частично.    
Backend API ↔ VLM/LLM: отдельные вызовы работают, но нет связки в общем пайплайне.  
История и избранное: сохраняются частично, требуется доработка.  
## Найденные проблемы
- Нет полноценного end‑to‑end сценария.
- UI реализован частично, нет сквозного тестирования.  
- Недостаточное покрытие тестами, особенно интеграционными.   
- UC8 (Отзывы) остаётся в техническом долге.
