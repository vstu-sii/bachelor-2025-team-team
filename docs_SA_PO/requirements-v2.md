# Итоги по требованиям AI HR Assistant
## Проверка соответствия Use‑cases
| Use Case | Название                                                | Проверяемая цель                                            | Реализуется в спринтах | Проверка соответствия  | Комментарий                                                                                                                                  |
| -------- | ------------------------------------------------------- | ----------------------------------------------------------- | ---------------------- | ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **UC1**  | Создание вакансии и загрузка кандидатов                 | Возможность загрузить описание вакансии и резюме кандидатов | **Спринт 1**           |  Реализовано                          | В Roadmap предусмотрено: загрузка файлов, парсинг, сохранение в базе.                                                                        |
| **UC2**  | Выбор варианта поиска и настройка критериев             | Гибкость настройки весов критериев анализа                  | **Спринт 2**           |  Частично                   | В MVP можно реализовать базовую форму выбора весов критериев (приоритет — “по умолчанию”); расширенные настройки могут быть добавлены позже. |
| **UC3**  | Анализ соответствия и ранжирование кандидатов           | AI-оценка навыков и построение рейтинга                     | **Спринт 2**           |  Частично                          | Включено в ядро MVP: LLM-анализ, скоринг и отображение списка кандидатов.                                                                    |
| **UC4**  | Генерация персонализированных вопросов и плана интервью | Автоматическая подготовка к интервью                        | **Спринт 3**           |  Частично                          | Используется LLM для анализа пробелов и генерации вопросов; реализуется API + интерфейс.                                                     |
| **UC5**  | Экспорт результатов                                     | Получение итогового отчёта в PDF для интервью               | **Спринт 3–4**         |  Частично                          | Есть экспорт в PDF; можно добавить другие форматы в будущем.                                                                                 |


## Валидация use‑cases через прототип 
| Показатель                         | Результат                                                                   |
| ---------------------------------- | --------------------------------------------------------------------------- |
| Полностью валидированные Use-cases | UC1                                                                         |
| Частично реализованные             | UC2,  UC3, UC4, UC5                                                         |
| Пользовательская обратная связь    | Интерфейс понятный, но нужно улучшить визуальную обратную связь при анализе |
| Степень готовности MVP к демо      | **≈ 85%** функционала покрывает целевые сценарии                            |

## Анализ отклонений от плана
1. Реализация фронтенда отстаёт от плана (UI отсутствует для части сценариев)
2. Низкое качество извлечения текста из PDF
3. Нестабильные ответы при больших текстах

## Обновление документации требований
- Требования UC1–UC9 остаются актуальными, но их статус уточнён (реализовано/частично/не реализовано)
- В документации требований необходимо обновить статусы и отметить отклонения
