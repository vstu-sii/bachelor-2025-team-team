# Настройка окружений
## 📌 Цель
Документ описывает конфигурацию окружений (Dev, Staging, Prod), управление переменными окружения, стратегию ротации секретов и планы резервного копирования/восстановления.

## ⚙️ Окружения

### Dev
- Используется SQLite как БД
- Логи пишутся в консоль
- Локальный запуск фронтенда
- Запуск на локальной машине (uvicorn main:app --reload)
- Подключение к тестовой версии LLM API

### Staging
- Деплой на staging-сервер (Docker)
- БД: SQLite или MySQL (тестовый инстанс)
- Используется для интеграционного тестирования
- Подключение к LLM API с реальными ключами

### Prod
- Подключение к реальной MySQL-базе
- Frontend развернут на веб-сервере
- Настроено логирование и мониторинг ошибок
- Реальные запросы к нейронке

## Environment Variables

Пример `.env` файла:
- **Dev**: тестовые ключи, локальные сервисы  
- **Staging**: отдельные ключи, ограниченные права  
- **Prod**: боевые ключи, доступ только через секрет‑менеджер

## Secrets Rotation
- Доступ к секретам только у CI/CD и администраторов.
- Продакшн-секреты — каждые 30–90 дней
- Новые секреты внедряются постепенно
- Удалять старые ключи после успешного внедрения новых
